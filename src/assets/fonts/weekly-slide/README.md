# Tipografías de la publicación semanal

Fraunces (peso variable 600–800) e IBM Plex Mono (400 y 600), correspondientes al HTML de referencia aportado por el usuario. Se sirven localmente desde Vite; el componente no consulta Google Fonts durante su uso.

Fuentes: https://fonts.google.com/specimen/Fraunces y https://fonts.google.com/specimen/IBM+Plex+Mono. Los archivos WOFF2 se obtuvieron del CSS oficial de Google Fonts el 31 de octubre de 2026. Se conserva el subconjunto Latin, que incluye los caracteres habituales del español.
