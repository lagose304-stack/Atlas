# Reglas de Git y Despliegue

## Restricción de Subida a GitHub
- **Regla estricta**: El asistente NO debe ejecutar `git push` ni subir cambios a GitHub bajo ninguna circunstancia automática o implícita.
- **Condición requerida**: Solo se pueden subir cambios a GitHub cuando el usuario lo solicite expresamente por escrito en el chat (por ejemplo: "sube a github", "haz push", "sube los cambios").
- Mientras tanto, todos los cambios se mantienen en el entorno local.
